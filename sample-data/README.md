# Sample data

`fake-members.csv` is **made-up** member data in the same format as the Sign Up
form (name, school email, Eastern ID, skill level). The emails are `fakeNN@...`
and the IDs start with `9999`, so they are obviously not real people.

Use it to try the Players page and the import script. Do not put real member
data in this repository. Keep real lists on your own computer.

See `docs/importing-players.md` for how to turn a CSV into players.
